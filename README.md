# Oceania Mock Government Telescreen Portal (1984 Ingsoc)

An authentic, dystopian retro-futuristic CRT television broadcast portal for the mock government of **Oceania** (George Orwell's *1984*). Designed with green phosphor CRT aesthetics, cathode scanlines, analog television static fuzz, the four canonical ministries, state announcements, citizen services, and interactive roleplay sandboxes.

## Features

- **Ingsoc Telescreen Experience**:
  - Green phosphor cathode-ray tube framing (`#020703` / `#4ade80`).
  - Toggleable CRT scanlines raster and analog television static canvas overlay.
  - Web Audio API sound engine providing 50Hz mains hum, discordant telescreen horn chimes, mechanical typewriter key clicks, carriage bell, and Memory Hole incinerator whoosh.

- **The Four Canonical Ministries**:
  - **Ministry of Truth (Minitrue)**: Rectification orders, Newspeak Eleventh Edition progress, Fiction Department, and Recdep.
  - **Ministry of Peace (Minipax)**: Frontline War Telemetry against Eastasia/Eurasia and Floating Fortress deployments.
  - **Ministry of Plenty (Miniplenty)**: Economic scarcity quotas, 148% boot production figures, and celebrated 20-gram chocolate allotments.
  - **Ministry of Love (Miniluv)**: Thought Police directives, Room 101 warning notices, and re-education protocols.

- **Interactive Roleplay Modules**:
  - **Interactive Two Minutes Hate Broadcast**: Emergency full-screen takeover with rising air-raid sirens, Emmanuel Goldstein condemnation sequence, and an interactive citizen loyalty chant button (`"B-B! ... B-B!"`) with a compliance meter.
  - **Minitrue History Revision Typewriter**: Interactive mechanical typewriter terminal where clerks rectify unpersons (e.g. Comrade Withers into Comrade Ogilvy) and incinerate compromised documents down the pneumatic Memory Hole with flame animations.

- **State Announcements & Decrees**:
  - Official Party bulletins categorized by Ministry and security classification (Public Broadcast, Party Members Only, Inner Party Eyes Only).

- **Government Directory**:
  - Roster of Inner and Outer Party personnel (Winston Smith, O'Brien, Syme, Tom Parsons, Comrade Ogilvy) with clearance dossiers, assigned offices, and surveillance status.

- **National Statistics (Doublethink Ledgers)**:
  - Fabricated production metrics and an interactive *Recalculate State Surplus* engine.

- **Citizen Services & Petitions**:
  - Petition for Razor Blade Allotments, Marriage Clearances, Victory Mansions repairs, and an automated Miniluv Thought Compliance Questionnaire (2+2=5).

- **Restricted & Classified Zones**:
  - **National Archives**: Formally closed to the public under Article 7-B with classified red stamps and Thought Police warning alarms.
  - **Foreign Affairs**: Under perpetual reconstruction — zero external diplomatic missions maintained.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Server**: Vite (running on port 3000)
- **Styling**: Tailwind CSS v4 + CRT Scanline/Phosphor Shaders
- **Audio**: Web Audio API Sound Synthesizer
- **Icons**: Lucide React
